# Contributing

This repository is primarily a capstone project and reproducibility artifact.

If contributions are accepted:

1. open an issue describing the proposed change;
2. do not commit private student data or credentials;
3. preserve the frozen final holdout benchmark;
4. do not change the 0.48 production threshold based on the final holdout;
5. add or update tests for reusable code;
6. document any change that affects fairness, explainability, or governance.

Model redevelopment and mitigation experiments should use new development and validation data.
