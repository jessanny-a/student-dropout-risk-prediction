# Security and Privacy

This repository is intended for a public academic portfolio and must not contain private institutional student data, credentials, API keys, or personally identifiable information.

## Reporting a Concern

If you discover a credential, private student record, or other sensitive information in a published copy of this repository, remove public access to the affected artifact immediately and rotate any exposed credentials before restoring the repository.

## Model Use Safety

The model is approved for **supportive decision support only**. It must not autonomously trigger dismissal, admission decisions, scholarship denial, disciplinary action, or denial of institutional services.
